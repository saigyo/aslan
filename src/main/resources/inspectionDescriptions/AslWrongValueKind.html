Reports a value whose basic kind does not fit its field: text where a number or a Boolean is expected, a mapping where a list is expected, an empty value for a field that does not accept null, and similar.

AWS documents that it rejects such a definition, so this is reported as an error. Placeholders, JSONata strings where JSONata may be used, unresolved aliases and plain YAML values that YAML 1.1 and 1.2 read as different types (such as yes or 1_000) are never reported.
