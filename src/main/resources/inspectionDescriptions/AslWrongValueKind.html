Reports a value whose basic kind does not fit its field: text where a number or a Boolean is expected, a mapping where a list is expected, a number with a fraction where a whole number is expected, a mapping or a list as the value of a key that ends in .$, an empty value for a required field, and similar.

AWS rejects such a definition, so this is reported as an error. Placeholders, JSONata strings where JSONata may be used, unresolved aliases, YAML mappings and lists with a tag such as !Join or !If, and plain YAML values that YAML 1.1 and 1.2 read as different types (such as yes or 1_000) are never reported. A whole number written with a decimal point, such as 5.0, is reported in a JSON file only: AWS rejects it as written, but a tool that converts YAML may send it as 5.
