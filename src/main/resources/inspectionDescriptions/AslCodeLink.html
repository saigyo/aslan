Reports a file path in a comment of an ASL file, or in a Comment field, that names no file, and a type after the path (path#Type) that the file neither declares nor contains.

Only words that look like paths are checked: they hold a /, end in a file extension and are not part of a URL. A path is looked up from the ASL file's folder, then from the content roots that hold it, the root of its version control repository and the project's base folder.
