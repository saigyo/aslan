Reports a read $name in a JSONPath string, such as InputPath or a .$ field, of a variable that is not assigned where the state can read it: assigned nowhere, only inside a Map or a Parallel branch, only in another branch, or only outside a Distributed Map. Step Functions rejects the definition: the variable is not defined.

A state machine that does not say every name assigned in it, for example through a deployment-time placeholder in Assign or States, is not checked.
