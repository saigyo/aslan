Reports a read $name in a JSONata expression inside the item processor of a Distributed Map, of a variable that only a state machine around the Map assigns, where that assignment comes before the flow enters the Map. Step Functions rejects the definition: the states of a Distributed Map's child workflow can only read the variables assigned in that child workflow.

An outer assignment counts as for the inspection of outer assignments in nested state machines: from a state's own Assign along its Next and its Default, from a Catcher's or a Choice rule's Assign along its own Next, also through a loop. A read whose name is assigned only after the Map, in its own Assign or in its Catchers is reported as a warning by the inspection for variables not assigned where they are read. Where the flow of the outer state machine is not known, it is not reported as an error either.

A call $name(...), an expression that contains a deployment-time placeholder outside a string literal or has a syntax error, and a state machine that does not say every name assigned in it are not checked.
