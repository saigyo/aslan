Reports a read $name in a JSONata expression inside the item processor of a Distributed Map, of a variable that only a state machine around the Map assigns. Step Functions rejects the definition: the states of a Distributed Map's child workflow can only read the variables assigned in that child workflow.

A call $name(...), an expression that contains a deployment-time placeholder outside a string literal or has a syntax error, and a state machine that does not say every name assigned in it are not checked.
