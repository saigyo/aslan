Reports a JSONata expression, a string between {% and %}, that the JSONata parser rejects, and marks the characters where the parser gives up. Step Functions rejects such a definition when it is created.

An expression that contains a deployment-time placeholder such as ${Name} outside a string literal is not checked, because the deployment tool changes the expression. A placeholder inside a string literal does not stop the check. To switch the check off, disable this inspection in Settings | Editor | Inspections | Amazon States Language.
