Reports a path in a JSONPath field, such as InputPath, ItemsPath or Variable, that does not start with $; ErrorPath and CausePath may also hold an intrinsic function. ResultPath must be $ or a reference path that starts with $. or $[. In Parameters, ResultSelector, ItemSelector and Credentials of a JSONPath state, the value of a key that ends in .$ must be a path or the call of an intrinsic function.

The definition validation of Step Functions rejects such a definition, which means the state machine cannot be created or updated, so this is reported as an error. Whether a path that starts with $ is well formed, and whether a variable it names exists, is not judged.
