Reports the RoleArn in the Credentials of a Task state when it does not have the form of an IAM role ARN, arn:partition:iam::account:role/name. A value that contains a placeholder, a JSONata expression in a JSONata state and a path or intrinsic function under RoleArn.$ are not checked.

The definition validation of Step Functions rejects such a value with the error "The value for the 'RoleArn' field is not a valid IAM role ARN", and an error there means the state machine cannot be created or updated, so this is reported as an error.
