Reports a field that does not apply where it is used: in a ReaderConfig, CSVDelimiter, CSVHeaderLocation or CSVHeaders when InputType is neither CSV nor MANIFEST, ItemsPointer when InputType is not JSON, InputType together with ManifestType: S3_INVENTORY, and Transformation when the reader gets a single object; on a Task state, Credentials when the resource is an activity.

The definition validation of Step Functions rejects such a definition, which means the state machine cannot be created or updated, so this is reported as an error.
