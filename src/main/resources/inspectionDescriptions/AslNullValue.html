Reports a field that is present but has no value where AWS does not accept that: written with nothing after the colon, or as null or ~. This covers the optional fields with a fixed kind of value, such as Comment, TimeoutSeconds or Retry, and the free-form fields Assign, Items, Credentials and the Parameters or Arguments of a Task state.

The definition validation of Step Functions rejects such a definition, which means the state machine cannot be created or updated, so this is reported as an error. A null is not reported where AWS accepts it: in InputPath, OutputPath and ResultPath, in the Error of a Fail state, and in free-form fields such as Output, Result, ResultSelector and ItemSelector. A null in a required field or as a transition target such as Next is reported as a value of the wrong kind instead.
