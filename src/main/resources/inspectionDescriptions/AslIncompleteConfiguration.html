Reports a Map setting that lacks a field it needs: a ProcessorConfig in DISTRIBUTED mode without ExecutionType; an ItemReader or a ResultWriter with a Resource but without its Parameters or Arguments; an ItemReader that gets a single object without a ReaderConfig; a ReaderConfig with InputType: CSV but no CSVHeaderLocation, with CSVHeaderLocation: GIVEN but no CSVHeaders, with ManifestType: ATHENA_DATA or Transformation: LOAD_AND_FLATTEN but no InputType.

The definition validation of Step Functions rejects such a definition, which means the state machine cannot be created or updated, so this is reported as an error.
