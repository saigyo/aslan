Reports a Map setting that lacks a field it needs: an ItemBatcher without any of MaxItemsPerBatch, MaxInputBytesPerBatch and their Path forms; a ResultWriter with neither Resource nor WriterConfig; a ProcessorConfig in DISTRIBUTED mode without ExecutionType; a ReaderConfig with Transformation: LOAD_AND_FLATTEN but no InputType, or with CSVHeaderLocation: GIVEN but no CSVHeaders.

It is only a warning: the specification or the developer guide states these requirements, but no AWS source documents that a definition breaking them is rejected.
