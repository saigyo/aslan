Reports a string in a JSONata state that starts with {% but does not end with %}, where Step Functions evaluates it: as the value of a field that accepts a JSONata expression, such as Condition or TimeoutSeconds, and anywhere inside free-form data such as Arguments, Output or Assign. A folded or literal block scalar that keeps its final line break does not end with %}.

AWS documents that it rejects such a definition, so this is reported as an error. Fields that AWS never evaluates, such as Comment, are not checked, and neither is a string that contains a placeholder, because the substituted text may close the expression.
