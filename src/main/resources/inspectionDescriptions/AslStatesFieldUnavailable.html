Reports a field of the reserved variable $states in a JSONata expression that does not exist where the expression is evaluated. Step Functions rejects the definition when it is created.

$states.result exists only in the Output and Assign of a Task, Map or Parallel state, and $states.errorOutput only in the Output and Assign of a catcher. Any name other than input, context, result and errorOutput is reported everywhere. An expression that several states use through a YAML alias is reported when one of these uses lacks the field. A filter, binding, order-by or group-by on the field changes nothing: $states.result[0] is reported where $states.result is. A wildcard $states.* is reported everywhere. AWS decides by the name, so a local variable named $states followed by a field is checked the same way; a block around it, as in ($states).result, is not. The fields below $states.context are not checked.

An expression that contains a deployment-time placeholder such as ${Name} outside a string literal is not checked. To switch the check off, disable this inspection in Settings | Editor | Inspections | Amazon States Language.
