Reports a field of the reserved variable $states in a JSONata expression that does not exist where the expression is evaluated. Step Functions rejects the definition when it is created.

$states.result exists only in the Output and Assign of a Task, Map or Parallel state, and $states.errorOutput only in the Output and Assign of a catcher. Any name other than input, context, result and errorOutput is reported everywhere. An expression that several states use through a YAML alias is reported when one of these uses lacks the field. The fields below $states.context are not checked, and a local variable named $states is not the reserved variable.

An expression that contains a deployment-time placeholder such as ${Name} outside a string literal is not checked. To switch the check off, disable this inspection in Settings | Editor | Inspections | Amazon States Language.
