Reports a field name that the Amazon States Language does not define. Free-form data such as Arguments is not looked into; Credentials is, since it only takes RoleArn.

The definition validation of Step Functions rejects an unknown field with "Field is not supported", so this is reported as an error. The field names the plugin knows were compared with AWS in every position of a definition. Should AWS add a field that the plugin does not know yet, the level of this inspection can be lowered here until the plugin is updated.
