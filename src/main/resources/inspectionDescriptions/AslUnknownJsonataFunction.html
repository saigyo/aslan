Reports a call of a function $name that is neither a JSONata built-in function, nor one of the functions Step Functions adds, nor a variable declared in the expression. Step Functions accepts the definition with a warning that the variable is possibly not defined; the call fails when the state runs.

An expression that contains a deployment-time placeholder such as ${Name} outside a string literal is not checked. To switch the check off, disable this inspection in Settings | Editor | Inspections | Amazon States Language.
