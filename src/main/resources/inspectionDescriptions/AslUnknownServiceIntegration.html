Reports the Resource of a Task state when it is written as a service integration, arn:aws:states:::service:action, but is none of the optimised integrations and patterns the plugin knows, such as a misspelt service or an action that only the AWS SDK integration offers. An AWS SDK integration, aws-sdk:service:action, is checked for its form only.

It is only a warning: Step Functions gains integrations over time, and the list in the plugin can be behind.
