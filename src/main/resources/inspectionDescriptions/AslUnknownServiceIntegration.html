Reports the Resource of a Task state when it is written as a service integration, arn:aws:states:::service:action, but is none of the optimised integrations and patterns the plugin knows, such as a misspelt service or an action that only the AWS SDK integration offers.

The definition validation of Step Functions rejects an integration it does not recognise. This is still only a warning: Step Functions gains integrations over time, they are not available in every region, and the list in the plugin can be behind. An AWS SDK integration, aws-sdk:service:action, is checked for its form only, by the inspection "Resource that AWS rejects".
