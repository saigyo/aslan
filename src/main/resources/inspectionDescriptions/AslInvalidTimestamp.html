Reports a Timestamp of a Wait state, or the value of a timestamp comparison in a Choice rule, that is not an RFC 3339 date and time that exists, such as 2026-03-14T01:59:00Z. A time zone is required: Z or an offset such as +01:00.

The definition validation of Step Functions rejects such a definition, which means the state machine cannot be created or updated, so this is reported as an error. AWS accepts T and Z in lower case and a time without seconds, so these are not reported.
