Reports a read $name in a JSONata expression of a variable that is not assigned where the state can read it: neither in its own state machine nor in one around it. A Parallel branch cannot see the variables of another branch, and the states around a Map or Parallel state cannot see those assigned inside it.

It is a warning: Step Functions accepts such an expression with a warning that the variable is possibly not defined. A read inside a Distributed Map of a name assigned only around it is rejected, and reported as an error by its own inspection. A call $name(...) of a name that is not assigned is treated as a function call. An expression that contains a deployment-time placeholder outside a string literal or has a syntax error is not checked, nor is a state machine that does not say every name assigned in it.
