Reports a string in a JSONata state that contains {% or %} but does not start with {%, where Step Functions evaluates JSONata: as the value of a field that accepts a JSONata expression and anywhere inside free-form data such as Arguments, Output or Assign. A JSONata expression must fill the whole string, so text in front of {%, a space included, is not allowed.

The definition validation of Step Functions rejects such a string with "JSONata string must start with {% and end with %}", so this is reported as an error. A string that contains a placeholder is not checked, and a Comment may hold the delimiters as plain text.
