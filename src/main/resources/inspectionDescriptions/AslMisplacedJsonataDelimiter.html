Reports a string in a JSONata state that contains {% or %} but does not start with {%, where Step Functions evaluates JSONata: as the value of a field that accepts a JSONata expression and anywhere inside free-form data such as Arguments, Output or Assign. Step Functions only evaluates a string that is wrapped in the delimiters as a whole, so text in front of {%, a space included, makes the whole value plain text.

It is only a warning, because such a string is a valid text value. A string that contains a placeholder is not checked.
