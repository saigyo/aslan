Reports a number outside the range AWS accepts, such as a negative MaxAttempts, a BackoffRate below 1 or a TimeoutSeconds above 99999999.

The definition validation of Step Functions rejects such a definition, which means the state machine cannot be created or updated, so this is reported as an error. The bounds are the ones AWS applies; it accepts 0 for IntervalSeconds, the batch limits of an ItemBatcher and the TimeoutSeconds of the state machine.
