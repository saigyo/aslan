  1. One selection, three views. The caret is inside ListReelFolder, so that state is selected in the structure view and in the diagram. Clicking a node or a structure entry moves the caret instead.
  2. JSONata reads as code. Expressions have a faint background. Strings, operators, variables and the built-in $states each have a colour.
  3. Variable highlighting. The caret is on $batch, so its occurrences are marked.
  4. Placeholders and state references stand out. ${ArchiveBucket} has its own colour, and transition targets are links.
  5. Diagram toolbar. A three-way switch for catch paths, and zoom controls.
  6. Details panel. Read-only facts about the selected state, with a control to collapse it.
